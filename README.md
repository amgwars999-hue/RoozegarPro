# 🗓️ Roozegar Pro — روزگار پرو

**Persian Calendar & Productivity Suite** | تقویم هوشمند فارسی با قابلیت‌های All-in-One

یک اپلیکیشن لاکچری و فول‌فیچر برای iOS و Android که ترکیبی از تقویم پیشرفته فارسی، یادداشت‌برداری دست‌نویس با قلم، مدیریت رویدادهای هوشمند با AI، و ابزارهای بهره‌وری حرفه‌ای است.

---

## ✨ ویژگی‌های کلیدی

### 📅 تقویم پیشرفته فارسی
- تبدیل دقیق تاریخ میلادی به شمسی و بالعکس با الگوریتم استاندارد
- نمایش مناسبت‌های رسمی، تعطیلات، و مناسبت‌های ایران باستان
- رنگ‌بندی هوشمند: تعطیلی‌ها قرمز، نمایشگاه‌ها نارنجی، جلسات آبی
- اتچ کردن تقویم‌های خارجی (مثل نمایشگاه‌های بین‌المللی تهران)

### 📝 یادداشت‌برداری دست‌نویس (Handwriting)
- بوم طراحی SVG با پشتیبانی از Apple Pencil و انگشت
- پس‌زمینه کاغذ شطرنجی (Grid) با افکت گوشه خمیده (Sticky Note)
- قالب‌های رنگی متنوع: زرد، کرم، قرمز، نارنجی، فیروزه‌ای و...
- چک‌لیست تعاملی داخل هر یادداشت

### 🤖 دستیار هوشمند AI
- ثبت رویداد با زبان طبیعی فارسی: *«فردا ساعت ۵ عصر با علی در نمایشگاه جلسه دارم»*
- تبدیل صوت به متن (Voice-to-Text) برای یادداشت‌های سریع
- پیشنهاد هوشمند زمان یادآوری بر اساس نوع رویداد

### 🔔 یادآوری و نوتیفیکیشن
- یادآوری‌های چندگانه و قابل شخصی‌سازی (دقیقه، ساعت، روز قبل)
- نمایش یادداشت روی Lock Screen (مانند اپلیکیشن Lock Screen Notes)
- نوتیفیکیشن‌های Sticky با اولویت بالا
- پشتیبانی از یادآوری SMS (آماده‌سازی برای نسخه بعدی)

### 🔒 امنیت و حریم خصوصی
- صندوقچه امن (Private Vault) با قفل بیومتریک (FaceID / TouchID / اثر انگشت)
- رمزنگاری داده‌ها در SQLite
- همگام‌سازی ابری رمزنگاری‌شده (Google Drive / iCloud)

### 🎨 شخصی‌سازی ظاهر
- حالت تاریک و روشن (Dark / Light Mode) + سیستم
- رنگ‌بندی اختصاصی تم (Lime, Gold, Orange, Red, Blue, Teal, ...)
- تغییر آیکون اپلیکیشن (مانند اسکرین‌شات‌های ارسالی)
- ویجت‌های Home Screen تعاملی (iOS 17+ / Android 14+)

### 👥 همکاری و اشتراک‌گذاری
- اشتراک‌گذاری تک رویداد با لینک / فایل ICS
- تقویم مشترک خانوادگی و کاری با Sync دوطرفه
- اسکنر هوشمند کارت ویزیت (OCR) برای نمایشگاه‌ها

## 🏗️ معماری فنی

```
RoozegarPro/
├── App.tsx                    # Entry point + Navigation
├── src/
│   ├── theme/
│   │   ├── colors.ts          # پالت رنگی و تم‌ها
│   │   └── ThemeContext.tsx   # مدیریت Dark/Light/Accent
│   ├── components/
│   │   ├── PersianCalendar.tsx   # گرید تقویم شمسی
│   │   ├── DrawingCanvas.tsx     # بوم نقاشی SVG
│   │   ├── StickyNote.tsx        # کارت یادداشت با گوشه خمیده
│   │   └── Toggle.tsx            # سوئیچ سفارشی
│   ├── screens/
│   │   ├── CalendarScreen.tsx    # صفحه اصلی تقویم
│   │   ├── DayDetailScreen.tsx   # جزئیات روز (نوت/رویداد/طراحی)
│   │   └── SettingsScreen.tsx    # تنظیمات (مشابه اسکرین‌شات)
│   ├── database/
│   │   ├── schema.sql            # اسکیمای SQLite
│   │   └── db.ts                 # اتصال و مقداردهی اولیه
│   ├── utils/
│   │   ├── persianDate.ts        # تبدیل تاریخ شمسی/میلادی
│   │   ├── holidays.ts           # مناسبت‌ها و تعطیلات
│   │   ├── notifications.ts      # مدیریت نوتیفیکیشن
│   │   └── aiAssistant.ts        # پردازش زبان طبیعی فارسی
│   ├── store/
│   │   └── appStore.ts           # Zustand state management
│   └── types/
│       └── index.ts              # TypeScript interfaces
```

### تکنولوژی‌ها
- **React Native 0.74** + **Expo SDK 51**
- **TypeScript** — تایپ‌سازی کامل
- **Zustand** — مدیریت State سبک و قدرتمند
- **Expo SQLite** — دیتابیس محلی
- **React Native SVG** — رندر گرافیکی بوم نقاشی
- **Expo Notifications** — نوتیفیکیشن‌های محلی
- **Expo Local Authentication** — بیومتریک

## 🚀 راه‌اندازی

### پیش‌نیازها
- Node.js 18+
- Expo CLI (`npm install -g expo-cli`)
- Xcode (برای iOS) / Android Studio (برای Android)

### نصب
```bash
cd RoozegarPro
npm install
npx expo prebuild
```

### اجرا
```bash
# iOS Simulator
npx expo run:ios

# Android Emulator
npx expo run:android

# Development server
npx expo start
```

## 🎨 سیستم طراحی (Design System)

### الهام بصری
- رنگ اصلی Lime `#C8E636` (از اسکرین‌شات Lock Screen Notes)
- گوشه‌های گرد (Radius 12–24)
- سایه‌های نرم و عمق (Elevation)
- پس‌زمینه کاغذ شطرنجی برای یادداشت‌ها
- آیکون‌های دست‌کشته و دوستانه

### فونت‌های پیشنهادی
- **Vazirmatn** (وزیرمتن) — برای متن‌های رابط کاربری
- **Lalezar** — برای اعداد و هدرها
- **Sahel** — برای یادداشت‌های دست‌نویس شبیه‌سازی شده
